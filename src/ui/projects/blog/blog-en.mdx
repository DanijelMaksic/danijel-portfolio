# Blog App

### A simple blogging app with a bookmark feature. Built with vanilla JavaScript using MVC architecture.

<HeroImage image={BlogImg} title="Blog App" />

My Blog is a vanilla **JavaScript** app that enables users to write articles. It is built in **HTML** with vanilla **CSS** and JavaScript. The app is structured in the MVC (Model-View-Controller) architecture model, which splits the application into three parts for easier understanding and less spaghetti code.
